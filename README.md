# Multimedia – ASE CSIE, anul III (grupa 1073)

Materiale de seminar și un mediu de pregătire pentru examenul de Multimedia: HTML, Canvas, SVG, Audio și Video în browser.

## Structură

| Folder | Ce conține |
|---|---|
| [`Pregatire-Examen/`](Pregatire-Examen/) | **Aici lucrez.** Planul pe 4 săptămâni, module (lecție, exerciții, soluții), modelele de examen, cheatsheet. Pornește de la [`Pregatire-Examen/README.md`](Pregatire-Examen/README.md). |
| [`Seminarii-prof/`](Seminarii-prof/) | Codul publicat de profesor pentru grupa 1073, din arhivele de pe platforma online. Numărul din nume = seminarul. Versiunea cu numărul cel mai mare e cea finală. |
| [`Seminarii-lucrate-in-clasa/`](Seminarii-lucrate-in-clasa/) | Ce am scris eu la seminarii (inclusiv câteva de la grupa 1075). |

Repo-ul oficial al cursului (laboratoare, exemple de curs, cursul în PDF): **[liviucotfas/ase-multimedia](https://github.com/liviucotfas/ase-multimedia)**. Nu e copiat aici; clonează-l separat.

## Cum rulezi

VS Code + extensia **Live Server**. Deschide folderul repo-ului și apoi *Open with Live Server* pe orice `index.html`.
Nu deschide fișierele cu dublu-click (`file://`), pentru că modulele ES și fișierele media nu se încarcă așa.
